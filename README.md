# 人生模拟器 V0.17.2

一个规则驱动的叙事人生模拟器。玩家会创建一个普通角色，在第五纪 1348 年的鲁恩王国廷根生活一年，每天做选择、移动、工作、调查、推理，并在普通生活与异常事件之间留下自己的经历。

> 数据决定世界真相，规则引擎决定能不能发生，叙事层只负责怎么讲。

## 项目状态

当前版本：`V0.17.2`

这是《诡秘人生模拟器》的第一块地基：先做一个不依赖 AI 的规则模拟核心。

V0.13 起进入“一年模拟”打磨阶段：目标不是继续扩得更大，而是让一个普通人能在廷根稳定生活、变化和遭遇一年。

## 当前目标

当前已经实现或正在打磨：

- 创建一个普通角色
- 在第五纪 1348 年的鲁恩生活一年
- 每天选择行动
- 根据行动改变状态
- 触发生活事件
- 通过选择决定事件后果
- 保存人生日志与经历标签
- 体验职业、房租、生活费和月度结算
- 在廷根不同地点之间移动
- 遭遇地点专属事件
- 生成不同角色背景和开局条件
- 收集异常线索
- 触发带前置条件的神秘接触事件
- 通过调查行动主动推进线索
- 与关键人物建立基础信任关系
- 通过推理行动组合线索
- 用结论解锁新的调查分支
- 积累地点熟悉度
- 关键人物会按日程移动
- 关系达到一定信任后解锁私人事件
- 调查会累积风险并可能引来注意
- 地点危险和调查风险会显示为可读等级
- 调查后会进入短暂冷却
- 角色拥有营养、睡眠、安稳和疲劳等日常状态
- 学习、工作、社交、闲逛会积累不同能力经验
- 月底会结算生活状态，不再只结算金钱
- 世界每天统一 Tick，集中推进 NPC、经济、事件图和地点变化
- NPC 拥有基础日常循环，会显示当天活动
- 异常失踪线从随机事件升级为事件图节点
- 事件图系统已有 10 个普通事件节点
- 新增季节事件：冬季煤价 / 开春泥路 / 盛夏酷暑 / 秋日集市（按月份季节触发）
- 新增职业专属事件：奖学金 / 师傅考校 / 月底查账 / 工钱缩水（按职业触发）
- 普通事件加入冷却机制，同一事件不会连续重复，一年节奏更自然
- 事件图系统已有 5 个异常事件节点
- 新增“非凡接触”事件图：失踪案 → 教会 → 游戏内线索 → 初次接触非凡者
- NPC 日程系统已有 21 个 NPC（20 个联系人 + 酒馆老板汤姆）
- 每个 NPC 都有 7 天循环活动（汤姆保留 4 段经典日程）
- 玩家可以通过廷根地图移动
- 地图会显示各地点 NPC 数量和可触发事件数量
- 不同地点会遇见不同 NPC 并触发不同事件
- 地图默认收起，点击后展开
- 跨年时角色年龄会正常增加

## 本地运行

### 网页版本

直接打开：

```text
web/index.html
```

### Python 命令行版本

Python 命令行版本仍然保留，作为规则验证用。

```powershell
python run.py
```

快速自动模拟：

```powershell
python run.py --auto 30
```

### 运行测试

```powershell
python -m pytest
```

测试按主题分文件（V0.17.2 起，共 63 项）：

```text
tests/
├── test_engine.py        引擎基础：行动、自动策略、事件图数据加载、NPC 创建
├── test_time.py          时间：日期推进、100 天/360 天/730 天、跨年、年龄正确
├── test_events.py        事件：条件满足必触发、不满足不触发、图推进、神秘链可达
├── test_save.py          存档：全量往返一致、旧存档兼容、多存档隔离
└── test_world_health.py  长跑健康：365/730/1095 天世界不腐坏、任意时刻可存档
```

设计原则：**模拟器最怕跑很久之后世界坏掉**，所以 `test_world_health.py` 用多种随机种子长跑并逐日校验——属性界内、世界状态界内、NPC 不腐坏、事件图不卡死、随时可存档往返。

## 当前版本重点

- 网页界面优先
- 事件拥有多个选择
- 选择会改变属性
- 选择会留下长期经历标签
- 职业会影响收入、压力、房租和生活成本
- 每 30 天进行一次月度结算
- 地点会影响可触发事件
- 移动会消耗当天行动、体力和金钱
- 每次新人生会随机姓名、年龄、家庭、阶层、倾向和初始职业
- 部分事件需要已有线索才会出现
- 调查结果会受到当前位置、联系人和线索影响
- 推理结论会记录在独立面板里
- 部分调查需要已有结论才会出现
- 社交、闲逛、工作、调查会提高当地熟悉度
- 调查需要目标人物当天也在同一地点
- 地点危险度、当地熟悉度和灵性会影响调查风险
- 高风险会触发被人注意的后续事件
- 风险等级会显示为平稳、紧张、危险、暴露
- 调查冷却会限制连续追查，非调查行动会让冷却回落
- 日常状态会影响健康、体力和压力
- 职业经验会降低工作压力，学识经验会提高学习收益
- 财务紧张会影响营养和居住安稳
- 事件图会根据线索、结论和选择推进阶段
- NPC 每天按生活循环改变位置和活动
- 世界 Tick 会推进城市紧张、经济压力和地点活跃度
- 普通生活事件被整理进“普通生活”事件图
- 异常失踪事件被整理进“异常失踪”事件图
- 已完成的非重复事件节点不会反复触发
- 20 个 NPC 会每天更新位置和活动
- 关系面板会显示 NPC 当天所在地点和正在做的事
- 地图节点会显示危险、熟悉度、活跃度、NPC 和事件数量
- 地图移动沿用地点消耗，并会按目标地点触发事件
- 地图收起时只显示当前位置摘要，移动后自动收起
- 时间进入新年时会写入日志，并让角色年龄增加 1 岁
- Python 核心新增 WorldEngine，统一承接 tick、行动处理、世界更新和事件触发
- Python 核心新增 EventSystem，事件从随机列表升级为 nodes/edges 事件图结构
- 新增 data/event_graphs.json，旧 events.json 作为兼容格式保留
- Python 核心新增 NPCSystem，NPC 从静态人物升级为带职业、目标、疲劳和日程的模拟生命
- 新增 data/npcs.json，NPC 每天会随 world tick 更新位置和当前活动
- Python 核心新增 WorldState，世界状态独立保存时间、天气、经济、城市、组织、事件和 NPC
- Python 事件图与网页版同步：普通生活 / 异常失踪 / 非凡接触 三张图共用同一份数据结构
- 事件条件支持地点列表、线索、结论、联系人存在等 Web 版字段（requires_*/locations/min_day）
- 事件条件新增季节（season）、月份（months）、职业（jobs）门槛
- 事件节点新增冷却（cooldown），触发后界面内不再重复，配合季节铺开一年节奏
- GameState 新增线索（clues）与结论（deductions）字段，链事件可依赖线索推进
- 神秘事件链已打通：车站失踪启事 → 报纸重叠 → 墙角符号 → 东区被跟踪 → 教会/调查抉择 → 非凡接触
- 第六阶段「再接诡秘」：Web 版新增非凡接触事件图（先不做 22 途径/神明/旧日）
  - 举报线：向教会举报 → 教堂旧币 → 符号之梦 → 初涉非凡
  - 追查线：决定追到底 → 深夜东区 → 符号之梦 → 初涉非凡
  - 世界面板显示「非凡接触」进度，故事弧推进到 初涉非凡
- 测试覆盖 100 天推进、跨年年龄、事件条件、存档保存加载一致性
- 测试覆盖 21 NPC 日程、神秘链全流程推进、线索条件判定、池图与链图区分

## 下一步

- 继续扩充季节与节日事件（冬春节庆、夏日集市），让一年有"过日子"的流逝感

- 社交层次：熟人 / 朋友 / 密友 / 恋人分级解锁互动
- 神秘链与 NPC 系统联动：值夜者、教士、非凡者按日程对线索作出反应
