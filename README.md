# 人生模拟器 V0.17.1

一个规则驱动的叙事人生模拟器。玩家会创建一个普通角色，在第五纪 1348 年的鲁恩王国廷根生活一年，每天做选择、移动、工作、调查、推理，并在普通生活与异常事件之间留下自己的经历。

> 数据决定世界真相，规则引擎决定能不能发生，叙事层只负责怎么讲。

## 项目状态

当前版本：`V0.17.1`

这是《诡秘人生模拟器》的第一块地基：先做一个不依赖 AI 的规则模拟核心。

V0.13 起进入“一年模拟”打磨阶段：目标不是继续扩得更大，而是让一个普通人能在廷根稳定生活、变化和遭遇一年。

## 当前目标

当前已经实现或正在打磨：

- 创建一个普通角色
- 在第五纪 1348 年的鲁恩生活一年
- 每天选择行动
- 根据行动改变状态
- 触发生活事件
- 通过选择决定事件后果
- 保存人生日志与经历标签
- 体验职业、房租、生活费和月度结算
- 在廷根不同地点之间移动
- 遭遇地点专属事件
- 生成不同角色背景和开局条件
- 收集异常线索
- 触发带前置条件的神秘接触事件
- 通过调查行动主动推进线索
- 与关键人物建立基础信任关系
- 通过推理行动组合线索
- 用结论解锁新的调查分支
- 积累地点熟悉度
- 关键人物会按日程移动
- 关系达到一定信任后解锁私人事件
- 调查会累积风险并可能引来注意
- 地点危险和调查风险会显示为可读等级
- 调查后会进入短暂冷却
- 角色拥有营养、睡眠、安稳和疲劳等日常状态
- 学习、工作、社交、闲逛会积累不同能力经验
- 月底会结算生活状态，不再只结算金钱
- 世界每天统一 Tick，集中推进 NPC、经济、事件图和地点变化
- NPC 拥有基础日常循环，会显示当天活动
- 异常失踪线从随机事件升级为事件图节点
- 事件图系统已有 10 个普通事件节点
- 事件图系统已有 5 个异常事件节点
- NPC 日程系统已有 20 个 NPC
- 每个 NPC 都有 7 天循环活动
- 玩家可以通过廷根地图移动
- 地图会显示各地点 NPC 数量和可触发事件数量
- 不同地点会遇见不同 NPC 并触发不同事件
- 地图默认收起，点击后展开
- 跨年时角色年龄会正常增加

## 本地运行

### 网页版本

直接打开：

```text
web/index.html
```

### Python 命令行版本

Python 命令行版本仍然保留，作为规则验证用。

```powershell
python run.py
```

快速自动模拟：

```powershell
python run.py --auto 30
```

### 运行测试

```powershell
python -m pytest
```

## 当前版本重点

- 网页界面优先
- 事件拥有多个选择
- 选择会改变属性
- 选择会留下长期经历标签
- 职业会影响收入、压力、房租和生活成本
- 每 30 天进行一次月度结算
- 地点会影响可触发事件
- 移动会消耗当天行动、体力和金钱
- 每次新人生会随机姓名、年龄、家庭、阶层、倾向和初始职业
- 部分事件需要已有线索才会出现
- 调查结果会受到当前位置、联系人和线索影响
- 推理结论会记录在独立面板里
- 部分调查需要已有结论才会出现
- 社交、闲逛、工作、调查会提高当地熟悉度
- 调查需要目标人物当天也在同一地点
- 地点危险度、当地熟悉度和灵性会影响调查风险
- 高风险会触发被人注意的后续事件
- 风险等级会显示为平稳、紧张、危险、暴露
- 调查冷却会限制连续追查，非调查行动会让冷却回落
- 日常状态会影响健康、体力和压力
- 职业经验会降低工作压力，学识经验会提高学习收益
- 财务紧张会影响营养和居住安稳
- 事件图会根据线索、结论和选择推进阶段
- NPC 每天按生活循环改变位置和活动
- 世界 Tick 会推进城市紧张、经济压力和地点活跃度
- 普通生活事件被整理进“普通生活”事件图
- 异常失踪事件被整理进“异常失踪”事件图
- 已完成的非重复事件节点不会反复触发
- 20 个 NPC 会每天更新位置和活动
- 关系面板会显示 NPC 当天所在地点和正在做的事
- 地图节点会显示危险、熟悉度、活跃度、NPC 和事件数量
- 地图移动沿用地点消耗，并会按目标地点触发事件
- 地图收起时只显示当前位置摘要，移动后自动收起
- 时间进入新年时会写入日志，并让角色年龄增加 1 岁
