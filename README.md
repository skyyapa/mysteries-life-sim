# 人生模拟器 V0.22

> 📌 **开发上下文**：接续开发前先读 [CONTEXT.md](CONTEXT.md) —— 记录当前实现状态、架构脉络、关键决策与下一步。

一个规则驱动的叙事人生模拟器。玩家会创建一个普通角色，在第五纪 1348 年的鲁恩王国廷根生活一年，每天做选择、移动、工作、调查、推理，并在普通生活与异常事件之间留下自己的经历。

> 数据决定世界真相，规则引擎决定能不能发生，叙事层只负责怎么讲。

## 当前目标

当前已经实现或正在打磨：

- 创建一个普通角色
- 在第五纪 1348 年的鲁恩生活一年
- 每天选择行动
- 根据行动改变状态
- 触发生活事件
- 通过选择决定事件后果
- 保存人生日志与经历标签
- 体验职业、房租、生活费和月度结算
- 在廷根不同地点之间移动
- 遭遇地点专属事件
- 生成不同角色背景和开局条件
- 收集异常线索
- 触发带前置条件的神秘接触事件
- 通过调查行动主动推进线索
- 与关键人物建立基础信任关系
- 关系按信任分层：生面孔 / 熟人（20+）/ 朋友（40+）/ 密友（60+）/ 挚友（80+）
- 社交行动随关系深度产生不同加成（朋友以上获得额外舒适与减压）
- 分层解锁专属事件：朋友的私事（信任 40+）、深夜里的话（信任 70+）
- 链事件一次性机制（onceTag）修复：温和警告 / 报纸边角 / 身后脚步不会无限重复；普通事件池可重复（repeatable + 冷却控频）
- 异常失踪链修复：墙角符号/身后脚步触发概率提升（8→24 / 26→30），并修复边条件自锁（报纸重叠不允许要求“符号自身的标签”），链可正常推进
- 事件时效性：异常链事件有窗口期（失踪启事 3~60 天、报纸边角 6~90 天、墙角符号 5~120 天、身后脚步 10~150 天），错过即失效；核心抉择（失踪案选择）不受时限；过期时留“错过”痕迹日志（每事件一次）
- 联系人面板显示信任层次标签（生面孔灰 / 熟人白 / 朋友绿 / 密友金 / 挚友红）
- 社交深化：泛社交封顶于朋友（信任 40），点击联系人卡片设为“深交对象”，此后社交专注此人且可突破 40 一路到挚友；深交对象不在同地时退化为泛社交
- 通过推理行动组合线索
- 用结论解锁新的调查分支
- 积累地点熟悉度
- 关键人物会按日程移动
- 关系达到一定信任后解锁私人事件
- 调查会累积风险并可能引来注意
- 地点危险和调查风险会显示为可读等级
- 调查后会进入短暂冷却
- 角色拥有营养、睡眠、安稳和疲劳等日常状态
- 学习、工作、社交、闲逛会积累不同能力经验
- 月底会结算生活状态，不再只结算金钱
- 世界每天统一 Tick，集中推进 NPC、经济、事件图和地点变化

## 运行方式

**自动生活（点击式）**：主角自己安排日常——点「过一天」推进一天，系统根据状态智能选择行动（健康低→休息、没钱→工作、压力高→社交、有线索→调查/推理、有余钱→存钱），**遇到事件才停下让你抉择**。日志区域占据主屏，纯阅读推进。右上角徽章提示"主角自动生活 · 点「过一天」推进"。

网页版本：

```text
web/index.html
```

### Python 命令行版本

Python 命令行版本仍然保留，作为规则验证用。

```powershell
python run.py
```

快速自动模拟：

```powershell
python run.py --auto 30
```

### 运行测试

```powershell
python -m pytest
```

测试按主题分文件（共 233 项，含数据校验回归）：

```text
tests/
├── test_engine.py        引擎基础：行动、自动策略、事件图数据加载、NPC 创建
├── test_time.py          时间：日期推进、100 天/360 天/730 天、跨年、年龄正确
├── test_events.py        事件：条件满足必触发、不满足不触发、图推进、神秘链可达
├── test_save.py          存档：全量往返一致、旧存档兼容、多存档隔离
└── test_world_health.py  长跑健康：365/730/1095 天世界不腐坏、任意时刻可存档
```

设计原则：**模拟器最怕跑很久之后世界坏掉**，所以 `test_world_health.py` 用多种随机种子长跑并逐日校验——属性界内、世界状态界内、NPC 不腐坏、事件图不卡死、随时可存档往返。
